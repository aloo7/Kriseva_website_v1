# Kriseva website

Public Astro website for Kriseva, focused on defence and space procurement in India. The application lives in `website/`; Cloudflare deploys `main`.

The signature illustration connects suppliers and procurement committees through TAS, Evaluator and an evidence trail. It includes detailed SVG shores, four focus views, a three-step guided story, explicit motion controls and a static fallback.
