# Kriseva website

Public Astro website for Kriseva, focused on defence and space procurement in India. The application lives in `website/`; Cloudflare deploys `main`.

The homepage explains Kriseva through a 24-second illustrated film, composed separately for phones and wider screens. An optional interactive bridge at `/bridge` connects suppliers and procurement committees through TAS, Evaluator and an evidence trail.
